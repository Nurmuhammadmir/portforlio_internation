Drop real screenshots of your projects in this folder and they'll automatically
replace the drawn browser-mockup placeholder on the portfolio.

Name each file to match its project number:

- project1.png (or .jpg / .jpeg / .webp)
- project2.png
- project3.png
- project4.png

No code changes needed — the site checks this folder for a matching file and
falls back to the placeholder mockup if it isn't found. A 16:10-ish landscape
screenshot (e.g. 1600×1000) looks best since it's cropped to that frame.
